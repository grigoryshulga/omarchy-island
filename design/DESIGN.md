# Island · дизайн-система

Это контракт интерфейса и работающий набор QML-компонентов. Новые экраны собираются из него; локальные размеры и цвета добавляются только при появлении новой смысловой роли.

## Публичный API для модулей

Поддерживаемый контракт компонентов, токенов и эффектов описан в [UI SDK 1.0](../docs/ui-sdk.md). [Шаблон модуля](../templates/module/README.md) и `bin/design-gallery --sdk` показывают его использование. Этот документ описывает визуальные принципы и внутреннее устройство; не все детали реализации являются публичным API.

## Основа

Спокойная поверхность, ясная типографика, небольшое число акцентов. Иерархию строим расстояниями, размером и весом текста. Вложенная карточка появляется, когда она объединяет самостоятельный объект или действие.

- Декоративных разделителей нет: ни между разделами, ни под вкладками, ни между строками настроек и уведомлениями. Промежуток между блоками составляет 24 единицы, внутри блока — 8–16.
- Постоянная рамка допустима у поля ввода. Выбранный вариант может иметь рамку; клавиатурный фокус всегда получает отчётливый контур. Внешняя рамка окна следует теме Omarchy.
- Один объект — одна точка открытия: заголовок сессии открывает T3. Дублирующая стрелка не нужна.
- Не дублируем смысл: вопрос с вариантами не получает подпись «Your answer is needed». Процент появляется только при наличии настоящего прогресса.
- Завершённый, работающий и ожидающий ответа объект различаются содержимым и индикатором; цвет не является единственным признаком состояния.

## Источники истины

| Уровень | Источник | Ответственность |
|---|---|---|
| Система | `qs.Commons.Color`, `qs.Commons.Style`, `qs.Commons.I18n` | Тема, семейство шрифта, масштаб, радиусы, уменьшение движения, локаль |
| Примитивы | `plugin/DesignTokens.js` | Шкалы, типографические роли, расчёт контраста; совместим с QML JS и Node |
| Семантика | `plugin/Design.qml` | Реактивный адаптер системных значений к ролям Island |
| Компоненты | `plugin/PlainText.qml`, `FeedbackButton.qml`, `ChoiceButton.qml` и остальные | Состояния, размеры, поведение и доступность |
| Композиции | Карточки, панели и `design/Gallery.qml` | Сборка компонентов без собственной палитры |

Island не читает и не копирует тему самостоятельно. Omarchy разрешает `colors.toml`, значения `shell.toml` темы и пользовательские переопределения `~/.config/omarchy/shell.toml`; Island получает уже разрешённые значения. Их изменение обновляет существующие компоненты, сохраняя форму, фокус и черновик.

## Типографика

Значения ниже указаны для стандартной базы Omarchy 12 px. Например, `body` берётся из `Style.font.title`: при базе 14 px текст автоматически становится 16 px. Явные переопределения шрифтов в теме также сохраняются. Семейство — `Style.font.family`, включая системный выбор моноширинного шрифта и Nerd Font.

| Роль `typeRole` | Размер / строка | Вес | Применение |
|---|---:|---:|---|
| `caption` | 12 / 16 | 400 | Время, проект, пояснение, вторичные данные |
| `label` | 13 / 20 | 500 | Кнопки, короткие элементы управления |
| `body` | 14 / 20 | 400 | Вопросы, содержимое, длинные варианты |
| `title` | 14 / 20 | 600 | Заголовок карточки и строки настройки |
| `section` | 16 / 24 | 600 | Название самостоятельного блока, трек |
| `page` | 24 / 32 | 600 | Главная дата и крупный заголовок |
| `metric` | 28 / 36 | 500 | Крупное значение |
| `hero` | 42 / 48 | 600 | Текущая температура |
| `bar` | 12 / 16 | 400 | Часы и компактный OSD; отдельная плотность панели |

Не уменьшаем длинный вопрос до мелкого текста. Варианты и пояснения переносятся полностью. Название сессии, имя файла или второстепенная метаинформация могут сокращаться многоточием. Кнопки используют короткие глаголы. Основной текст остаётся обычного веса, заголовки — полужирными; сплошной bold не создаёт иерархию.

## Геометрия

Всё проходит через `Style.space`, поэтому масштаб интерфейса и настройка межэлементных расстояний Omarchy продолжают работать.

| Токен | Базовое значение | Назначение |
|---|---:|---|
| `gap.micro` | 2 | Оптическая поправка |
| `gap.tight` | 4 | Подпись непосредственно под значением |
| `gap.small` | 8 | Связанные элементы, строки списка |
| `gap.medium` | 12 | Содержимое формы, отступы кнопки |
| `gap.large` | 16 | Внутреннее поле карточки и панели |
| `gap.section` | 24 | Самостоятельные блоки |
| `gap.page` | 32 | Крупные композиции |
| `gap.spacious` | 48 | Выставочные и пустые состояния |
| `controlHeight` | 36 | Обычная кнопка и вкладка |
| `compactControlHeight` | 32 | Вторичное действие |
| `inlineControlHeight` | 24 | Иконка действия в строке метаданных |
| `fieldHeight` | 40 | Поле ввода и выбор из списка |
| `optionHeight` | минимум 48 | Вариант с переносом; растёт вместе с текстом |

У карточки радиус системы. У кнопки и поля — `min(радиус системы, 8)`. При системном радиусе 0 поверхности строго прямоугольные. Круглая геометрия радио-индикатора и ручки слайдера обозначает их функцию и не является радиусом карточки.

У карточек нет фиксированной высоты по содержимому. Длинная форма прокручивается; фокусируемый элемент показывается в области просмотра. У T3 варианты занимают равные колонки, при ширине формы менее 380 единиц остаётся одна колонка. Последний нечётный вариант занимает всю строку. Поле собственного ответа и отправка находятся в одной строке.

## Цвет и темы

| Роль | Источник / правило |
|---|---|
| `canvas` | `Color.popups.background`, с системной прозрачностью |
| `opaqueCanvas` | Фон popup, скомпонованный с `Color.background` |
| `surface` | Фон + 4,5% цвета текста; карточка |
| `raised` | Фон + 8% цвета текста; поле или вложенное управление |
| `text` | `Color.popups.text`, с коррекцией контраста |
| `secondaryText` | `Color.muted`, с коррекцией контраста |
| `accent` | `Color.accent`, с коррекцией контраста |
| `danger` | `Color.urgent`, с коррекцией контраста |
| `info`, `success`, `warning` | `blue`, `green`, `yellow` из текущего `colors.toml`; запасные источники — ANSI `color4`, `color2`, `color3`, затем `Color.accent`; с коррекцией контраста |
| `selection` | Фон + 14% акцента |
| `selectedText`, `selectedSecondaryText` | Акцент и подпись, проверенные относительно выбранной поверхности |
| `focusRing` | Контрастный акцент; 2 px |
| `fieldBorder` | Вторичный цвет с контрастом для границы поля |
| `barText`, `barAccent`, `barDanger` | Контекст панели; часы продолжают принимать цвет от bar API |

Светлая тема не является инверсией тёмной: слои выводятся из её собственных фона и текста. Для подписи и акцента целевой контраст — не ниже 4,5:1; для границы поля — 3:1. Основной текст стремится к 7:1. Если исходный цвет не подходит, сохраняем его насколько возможно, смещая к наиболее читаемому нейтральному. При математически недостижимом контрасте выбирается этот нейтральный. В компонентах нет отдельных красных, зелёных или серых hex-цветов.

Статусы T3 используют `info` для работы, `success` для завершения, `warning` для запроса ввода и `danger` для ошибки; иконка и текст сохраняют смысл без цвета. Иконки проектов сохраняют заданный в T3 цвет, включая светлый и тёмный варианты его палитры; без заданного цвета используется `accent`.

Обычный успех обозначается галочкой и текстом. Ошибка и низкий заряд используют `danger`, запись — его версию для бара; активное подключение — акцент. Это работает и в монохромной теме.

Брайлевый рисунок остаётся визуальным слоем. Фоны информационных карточек непрозрачны: рисунок не проходит сквозь вопрос, варианты и основной текст. Прозрачность внешнего popup и его системная рамка сохраняются.

## Компоненты и состояния

| Компонент | API и правило |
|---|---|
| `PlainText` | `typeRole`, обычный `Text.PlainText`; шрифт, вес и высота строки из системы |
| `Surface` | `raised`; фон карточки без рамки |
| `SectionHeading` | `title`, `detail`; заголовок слева, вторичная информация справа |
| `FeedbackButton` | `variant: quiet / soft / primary`, `selected`, `compact`, `focusable`; адаптация native Button на `qs.Ui.BorderSurface` |
| `ActionButton` | Компактное вторичное действие |
| `TabButton` | `label`, `tabActive`; мягкая выбранная поверхность, без подчёркивания |
| `ChoiceButton` | `label`, `description`, `multiSelect`, `selected`; переносы и явный индикатор выбора |
| `DesignTextField` | Native TextField с общей геометрией, контрастным placeholder и фокусом |
| `DesignDropdown` | Native Dropdown; сохраняет клавиатуру и popup, получает общие цвета и высоты |
| `ControlSwitch` | Native ToggleSwitch; контрастная лицевая часть, системные переключение и направления |
| `BrailleProgress` | Общая точечная полоса для батареи, лимитов и ползунков; значение 0–1, семантический цвет, RTL |
| `IslandSlider` | Точечная полоса по умолчанию (`trackStyle: "braille"`), сплошная линия с ручкой через `"solid"`. Значение, шаг, движение мышью, колесо, стрелки, H/L, Home/End |
| `T3Spinner` | `active`, `tint`; общий индикатор работы для карточки и бара |
| `ListRow` | Заголовок, описание и текстовый статус; отдельные действия доступны с клавиатуры и не активируют строку; при узкой ширине переносятся вниз |
| `DataState` | Загрузка, пустой результат, ошибка, данные из кэша; действие восстановления принадлежит модулю, spinner останавливается при скрытии и reduced motion |
| `FormField` | Подпись и пояснение вокруг существующего редактора; ошибка заменяет пояснение, не пересоздавая поле и не теряя черновик |

Обычное состояние `quiet` прозрачно; `soft` обозначает отдельный элемент фоном. `primary` — одна основная операция в области. Hover и pressed используют состояния `Style`, выбранный элемент получает `selection`; focus — контур без изменения размеров. Недоступный элемент имеет прозрачность 0,45 и не принимает действие. Для нажатия не уменьшаем всю геометрию элемента.

Ревизия существующих элементов сохраняет эти принципы. У слайдера и переключателя единое обозначение недоступности. Клавиатурное поведение переключателя общее для SDK и встроенных панелей; строки настроек не обрабатывают его нажатия повторно. Поле с `invalid` получает цвет ошибки, но при фокусе приоритет остаётся у контура фокуса. Палитра, типографика, варианты кнопок и поверхности не заменяются отдельным оформлением для новых компонентов.

`bin/design-gallery --patterns --language ru` показывает новые композиции вместе с существующими элементами. Захват включает тёмную/светлую тему, квадратную монохромную геометрию, фокус, загрузку, ошибку, пустой результат, недоступность, reduced motion и узкий контейнер 380 px с увеличенным текстом. Это настоящий QML; offscreen-снимок не имитирует blur композитора. Стеклянность сохраняется у внешнего popup, а карточки остаются читаемыми и непрозрачными.

Быстрая обратная связь — 120 ms, переход — 180 ms, раскрытие — 240 ms, оборот спиннера — 900 ms. `Style.duration` и `Preferences.reduceMotion` имеют приоритет. При уменьшении движения состояния переходят в конечное положение, спиннер останавливается. Невидимые страницы и карточки вне viewport не запускают бесконечные эффекты. Специализированные брайлевые эффекты сохраняют собственную временную композицию.

В панели сохраняются Tab/Shift+Tab, Enter/Space, Escape, направления и сочетания Alt+1–4. Поля забирают ввод и движение каретки себе. Нативные системные панели сохраняют свою модель клавиатурного курсора. Направление текста и даты приходят из Omarchy I18n. Данные уведомлений и T3 никогда не становятся rich text или shell-кодом.

## Пример сборки

```qml
ColumnLayout {
  spacing: Design.gap.medium
  SectionHeading { Layout.fillWidth: true; title: strings.t("downloads.title") }
  PlainText { Layout.fillWidth: true; typeRole: "body"; wrapMode: Text.Wrap; text: message }
  RowLayout {
    DesignTextField { Layout.fillWidth: true; placeholderText: strings.t("t3.answer") }
    FeedbackButton { variant: "primary"; text: strings.t("t3.send"); focusable: true }
  }
}
```

## Миграция и проверка

На роли переведены Overview, уведомления и история, загрузки, T3, музыка и громкость, календарь, погода, батарея, Controls, настройки, бар и диктовка. Встроенные Audio/Bluetooth/Network/Tailscale/Monitors получают адаптированные компоненты и типографику при генерации кэша. Их разделители заменяются `ControlGap`, исходники системы не изменяются. Внутреннее поведение готовых `qs.Ui` компонентов остаётся нативным.

`bin/design-gallery` открывает изолированную нативную галерею. В ней работают кнопки, выбор вариантов, собственный ответ, фокус, переключение палитры, уменьшение движения, масштаб текста и узкая карточка. Ответы отправляются только локальной заглушке. Галерея ничего не сохраняет в настройках пользователя.

`bin/design-gallery --capture-dir /tmp/island-design` снимает dark/light/mono без показа окна. `bin/test` проверяет модели, компоненты и интеграции; проверки дизайн-системы включают смену темы без потери черновика, контраст, состояния, масштаб, квадратные углы и отсутствие декоративных разделителей. Перед изменением токена следует проверить все три палитры и длинные подписи.

Спиннер T3 — последовательность брайлевых символов с дискретной сменой кадра каждые 90 мс. Вращения и сглаженных дуг нет; при уменьшении движения и скрытии остаётся первый кадр.

Все всплывающие поверхности используют `Design.canvas` с исходной прозрачностью и `Design.popupBorder` из системного раздела `popups`. Это относится и к самостоятельной карточке T3, уведомлениям, Now Playing, громкости и диктовке. Отдельные Wayland-поверхности используют namespace `omarchy-island-popup`, поэтому получают одинаковый blur по правилам Hyprland.
