# Omarchy Island

Island brings notifications, activity and system information into the shell clock and its popup.

## Language

**Module**:
A registered feature with its own state, settings and views. Built-in features such as Notifications and Calendar use the same hosts as optional integrations. A module does not need to contribute every kind of view.

**Integration**:
An optional connection to a source of information or actions, such as T3 Code sessions or Agent Limits quotas. It is implemented as a module and can appear in several places in Island.

**Overview**:
The popup's summary of current activity, notifications and enabled integrations.

**Details**:
The expanded content of one Overview section, shown in place of the summary. Returning to the summary restores the user's previous position and focus.

**Indicator**:
A compact status beside the clock that can open the popup.

**Hover preview**:
The compact popup shown while the pointer rests over the clock, before the popup is pinned open.
